Kromabridge — quick reference · version 1.1

PC version: Kromabridge desktop shortcut. Raspberry Pi version: Wi-Fi Kromalaser (password kromalaser), then http://10.42.0.1:8080.

Top bar

▲ ▼ + namePrevious / next song list, and its name ("All": no list)
◀ ▶ + titlePrevious / next song (in the active list), its title and place
Open / CloseSwitches the harp fan on or off
SongOpen, Manage songs, new, save as, rename, delete, trash, MIDI import, song export / import
ListsChoose a list, Manage lists…, list export / import
LearningCreate beams from keyboard, Change a beam from keyboard
🔇Enable the harp sound on this device
🛑 PanicCuts every note, even those held by the pedal
⏻Shut the Pi down (wait for the "you can cut the power" message)
⚙App settings, harp settings, About (orange dot = settings not stored)

Beams (one tile per beam)

  • Tap the note name: choose another note.
  • -12 -1 +1 +12: octave / semitone; All beams: shift everything, or sort from low to high.
  • Chord: several notes for one beam.
  • ✕: delete this beam (the following ones move left; 5 beams minimum).
  • Cutting a beam lights up its tile.

The song

  • Everything is saved immediately.
  • Number of beams (5 to 15), MIDI output channel.
  • Change the synth sound: program (+ bank) sent on loading; per part if the song has parts.
  • Opening animation, transition between parts.
  • Parts A, B, C…: tap to change; ＋ add (blank or copy); drag to reorder; － delete. The song always starts from A.
  • Manage songs…: open, rename, delete; tick to delete or create a list.
  • Pi: USB key for export / import ("Save to the Pi USB key" box, "Import from the USB key…", then Eject the key).

Control track (DAW) — channel 16

Program nLoads song number n
C-2 (DAW)Open the harp
C#-2 (DAW)Close the harp
C-1, C#-1, D-1…Parts A, B, C…
PC: output to the Controle Harpe port. Pi: to its MIDI input. "Control from the DAW" box in the settings. A song's number = its place in "All songs".

Song lists

  • Lists > Manage lists…: create, rename, add songs.
  • Reorder: ☰ handle (drag) or ↑ ↓ arrows, then Apply.
  • Export / Import lists…: one list or all, with their songs.
  • Changing the order of "All songs" changes the numbers: the application offers to re-export the control tracks.

Harp settings (⚙)

  • Read the harp, then edit: sent at once, orange until stored.
  • Store in this song / in all songs / Restore.
  • Common to all songs box: for venue settings (width, sensitivity…).
  • ? button: explanation of each setting.
  • Colors tab: choose the colours, the application sets the lasers.

Keyboard learning

  • Create beams: play the notes, then Finish.
  • Change a beam: cut the beam (or tap its tile), play the note; Keep / Undo.
