Les rayons (une case par rayon)

  • Toucher le nom de la note : choisir une autre note.
  • -12 -1 +1 +12 : octave / demi-ton ; Tous les rayons : décaler tout, ou ranger du grave à l'aigu.
  • Accord : plusieurs notes pour un rayon.
  • ✕ : supprimer ce rayon (les suivants se décalent ; 5 rayons minimum).
  • Couper un rayon allume sa case.

Le morceau

  • Tout est enregistré immédiatement.
  • Nombre de rayons (5 à 15), canal MIDI de sortie.
  • Changer le son du synthé : programme (+ banque) envoyé au chargement ; par partie si le morceau a des parties.
  • Animation d'ouverture, transition entre les parties.
  • Parties A, B, C… : toucher pour changer ; ＋ ajouter (vierge ou copie) ; glisser pour réordonner ; － supprimer. Le morceau repart toujours de A.
  • Gérer les morceaux… : ouvrir, renommer, supprimer ; cocher pour supprimer ou créer une liste.
  • Pi : clé USB pour l'export / import (case « Enregistrer sur la clé », « Importer depuis la clé USB… », puis Éjecter la clé).

Piste de contrôle (DAW) — canal 16

Programme nCharge le morceau n° n
C-2 (do-1)Ouvrir la harpe
C#-2 (do#-1)Fermer la harpe
C-1, C#-1, D-1…Parties A, B, C…
PC : sortie vers le port Controle Harpe. Pi : vers son entrée MIDI. Case « Contrôle par le DAW » dans les paramètres. Le n° d'un morceau = sa place dans « Tous les morceaux ».

Listes de morceaux

  • Listes > Gérer les listes… : créer, renommer, ajouter des morceaux.
  • Réordonner : poignée ☰ (glisser) ou flèches ↑ ↓, puis Valider.
  • Exporter / Importer des listes… : une liste ou toutes, avec leurs morceaux.
  • Changer l'ordre de « Tous les morceaux » change les numéros : l'application propose de réexporter les pistes de contrôle.

Réglages de la harpe (⚙)

  • Lire la harpe, puis modifier : envoyé tout de suite, en orange tant que non mémorisé.
  • Mémoriser dans ce morceau / dans tous / Rétablir.
  • Case commun à tous les morceaux : pour les réglages du lieu (largeur, sensibilité…).
  • Bouton ? : explication de chaque réglage.
  • Onglet Couleurs : choisir les couleurs, l'application règle les lasers.

Apprentissage au clavier

  • Créer les rayons : jouer les notes, puis Terminer.
  • Changer un rayon : couper le rayon (ou toucher sa case), jouer la note ; Garder / Annuler.
